## Состав выполненной работы

- `db/foodexpress_levichev.backup` — архив PostgreSQL в custom-формате.
- `db/constraints.md` — обоснования ограничений.
- `db/tests.md` — протокол выполненных проверок.
- `db/schema/grants.sql` — создание роли `inspector` и выдача прав.

## Восстановление и проверка

В целевой базе заранее должна существовать схема `exts` с расширением
`uuid-ossp` (BR-13.3). Восстановите custom-архив с помощью pg_restore
или интерфейса DBeaver в заранее подготовленную базу.

После восстановления примените `db/schema/grants.sql` от имени роли,
имеющей право создавать роли и выдавать привилегии, если требуемые права
не были восстановлены вместе с архивом.

**Примечание:** исходные SQL-скрипты создания всех объектов схемы
отдельно в предоставленном проекте отсутствуют. Для выполнения
требования `db/schema/*.sql` их необходимо экспортировать из рабочей
базы данных, сохранив определения объектов.
